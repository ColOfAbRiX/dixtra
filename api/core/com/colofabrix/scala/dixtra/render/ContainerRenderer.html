ContainerRenderer

com.colofabrix.scala.dixtra.render.ContainerRenderer
final class ContainerRenderer(ctx: RenderContext, signatures: SignatureRenderer, renderRegion: (Int, Int, List[Stat]) => String)

Renders containers (object / class / trait).

The header of a class or trait is laid out by ContainerHeader; the rest of the header, the braces and the surrounding whitespace are preserved, and each member statement is formatted in place at its own source column. A container whose new header does not verify keeps its original header.

The blank lines at the edges of the body follow blank-lines.body-edges for the container's construct (see EdgeBlankLines); a braceless (Scala 3 :) body has no closing edge.

Value parameters

ctx

The shared render context.

renderRegion

Renders the members found in a region of the source (supplied by the router to break the recursion cycle).

signatures

The signature renderer, for constructor parameters.
