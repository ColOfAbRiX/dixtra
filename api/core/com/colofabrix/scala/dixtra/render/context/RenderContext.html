RenderContext

com.colofabrix.scala.dixtra.render.context.RenderContext
final class RenderContext(original: String, val config: Config)

The shared context for one formatting run.

Every renderer receives this context so the source, its tokens and the configuration are captured once rather than threaded through every call. It is a facade: positional token queries come from SourceTokens and source slices as documents from SourceDocs, both exported here; the context itself adds the width checks and the splicing of rendered children into the source.

Value parameters

config

The active formatting configuration.

original

The full source text being formatted.
