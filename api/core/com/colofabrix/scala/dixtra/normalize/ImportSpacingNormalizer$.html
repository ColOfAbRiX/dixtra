ImportSpacingNormalizer

com.colofabrix.scala.dixtra.normalize.ImportSpacingNormalizer
object ImportSpacingNormalizer

The blank lines between imports: always removed.

Between an import and the next one only comments stay, each on its line; an import ends at the first line break outside its braces that does not follow a comma. A gap with a comment over several lines is left as it is, so that the blank lines inside the comment stay. The pass runs before rendering, so the layout sees the imports as one group.

The pass is token-aware; if the text cannot be tokenised, it is returned unchanged (safety net).
