final class ContainerRenderer(ctx: RenderContext, signatures: SignatureRenderer, renderRegion: (Int, Int, List[Stat]) => String)

Renders containers (object / class / trait).

Renders containers (object / class / trait).

The header of a class or trait is laid out by ContainerHeader; the rest of the header, the braces and the surrounding whitespace are preserved, and each member statement is formatted in place at its own source column. A container whose new header does not verify keeps its original header.

The blank lines at the edges of the body follow blank-lines.body-edges for the container's construct (see EdgeBlankLines); a braceless (Scala 3 :) body has no closing edge.

final class DefinitionAlignment(ctx: RenderContext, assignments: AssignmentRenderer, defs: DefRenderer)

Renders the definitions among a run of statements (val, lazy val, var, def, given alias, type alias), aligning the = of consecutive one-line definitions of the same alignment group (alignment.assignment-groups, see Alignment). A definition that would not fit once aligned has its body moved below the =, and the definitions before and after it align separately. The import and export clauses among them are rendered too, never aligned.

final class TreeRenderer(original: String, config: Config)

The dixtra tree renderer: the single routing point over a parsed compilation unit.

The dixtra tree renderer: the single routing point over a parsed compilation unit.

It owns the shared com.colofabrix.scala.dixtra.render.context.RenderContext and the per-construct renderers, dispatching each node to its rule. Any construct without a rule falls back to the safety net (verbatim source), so the tool never corrupts unsupported code. Text between handled nodes (whitespace, blank lines, comments) is preserved exactly by splicing formatted node slices back into the original source.

Formatting is recursive: the members of containers, and the definitions and expressions nested in blocks, case bodies and lambdas, all follow the same rules. Consecutive one-line definitions align their = (see Alignment). Every rendered definition or statement is verified, at whatever depth: if it does not parse back to an equivalent tree with the same comments, its original source is kept instead.

Value parameters

config

The active formatting configuration.

original

The full source text being formatted.
