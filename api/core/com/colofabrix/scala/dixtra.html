object Dixtra

Public entry point for the Dixtra Scala 3 formatter.

Public entry point for the Dixtra Scala 3 formatter.

The formatter is a pure function from source text to formatted source text. It first collapses redundant whitespace, parses the result with Scalameta and renders the tree according to the style rules of Dixtra. Any construct not yet supported falls back to the safety net, which reproduces the source verbatim, so the tool never corrupts code.

As a final guarantee the output is re-parsed and compared with the original input: if the program structure or the comments differ, formatting fails with an UnsafeOutputError instead of returning corrupted code.
