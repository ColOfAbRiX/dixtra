final class ResultCache

The files that earlier runs found formatted, so that a run does not format them again.

A file is known by a digest of its path, its content, its configuration and the code of dixtra: a change to any of them formats the file again. The cache file holds the digests of the files the last run found unchanged, one a line. The command line keeps it in the cache directory of the user (see ResultCache.userFile), the sbt plugin in the target directory of the project.

Value parameters

code

The digest of the code of dixtra, or None when it is not known: then nothing is cached.

previous

The digests of the files found unchanged by the last run.
