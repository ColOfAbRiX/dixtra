object ConfigAliases

The aliases of the settings: a name that sets one or more settings at once.

The aliases of the settings: a name that sets one or more settings at once.

The aliases are defined in the internal resource aliases.conf, the one place to add, change or remove them. The tests check that every target is a setting of reference.conf, that no alias is a setting itself, and that the targets of an alias accept the same values.

Aliases are resolved when a configuration is loaded, on the settings the user wrote and before the defaults are merged in, so the rest of dixtra never sees them. An alias sets each of its targets to its value. When a setting is given more than once, directly or through aliases, every value must agree, else the configuration is rejected.

object ConfigCli

CLI option definitions and the lookup of the configuration file for Config. The loading itself is ConfigLoading, the defaults it loads over ConfigSchema, and the pureconfig instances ConfigInstances.

CLI option definitions and the lookup of the configuration file for Config. The loading itself is ConfigLoading, the defaults it loads over ConfigSchema, and the pureconfig instances ConfigInstances.

The configuration is the defaults in reference.conf overridden by, in order of precedence: --config-string, --config-path, or the nearest .dixtra.conf found walking up from each formatted path.

A configuration states the version of its schema in config-version, a semantic version (1.0.0). One without it is read as the current version; one with another major version, or written for a later version, is rejected.
