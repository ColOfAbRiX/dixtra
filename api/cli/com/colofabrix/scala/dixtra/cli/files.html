object AtomicFiles

UTF-8 file reads and atomic rewrites.

UTF-8 file reads and atomic rewrites.

A rewrite goes through a temporary file beside the target that is atomically moved over it, keeping the target's permissions, so a file is never left half-written. Symbolic links are resolved so the link itself is preserved. The move is retried a few times when it fails because another process holds the target open, as an antivirus or an IDE indexer briefly does on Windows.

object SourceFiles

Discovers the Scala sources named by the CLI paths: a file is taken as is and a directory is walked recursively for every .scala and .sbt file, listed in path order so that the result does not depend on the file system. Hidden directories and target directories inside it are skipped, and the files are selected by include and exclude glob patterns relative to it.
