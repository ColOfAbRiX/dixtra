object Main extends IODeclineApp[CliOptions]

Command-line entry point for the dixtra formatter.

Formats one or more Scala files and/or whole directories in place, or verifies them without writing when --check is supplied. Argument parsing is provided by decline via the declinio Cats Effect integration.
